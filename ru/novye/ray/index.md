## Диодная сборка из 12 лазерных баров

Ray использует диодную сборку из 12 лазерных баров.

Лазерный бар представляет собой полупроводниковый элемент с излучающими структурами. Несколько таких элементов образуют часть источника лазерного излучения.

Для нормальной работы сборки важны правильное охлаждение, управление электрическим током и состояние соединений.

Количество баров само по себе не является показателем эффективности эпиляции.

## Оптическая технология FAC

Ray использует технологию Fast Axis Collimation, предназначенную для уменьшения расходимости лазерного излучения по одной из осей.

Оптическая система помогает формировать и направлять излучение диодной сборки.

Состояние оптических компонентов имеет значение для правильной работы лазерного оборудования.
